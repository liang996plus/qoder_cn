# hiagent 辅助 Web 服务 — 应用启动脚本 需求说明

---

## 一、项目概述

为 hiagent 辅助 Web 服务提供一键启动脚本，自动完成环境检查、依赖安装、配置初始化和服务启动，降低部署和运行门槛。

---

## 二、功能需求

### 2.1 环境检查
- 检测系统是否安装 Python，版本 >= 3.10
- 检测是否安装 pip
- 未满足条件时给出明确的安装提示并退出

### 2.2 虚拟环境管理
- 检测项目根目录是否存在 `venv/` 虚拟环境
- 不存在时自动创建
- 自动激活虚拟环境

### 2.3 依赖安装
- 检测 `requirements.txt` 是否变更（对比 venv 内已安装记录）
- 有变更时自动执行 `pip install -r requirements.txt`
- 首次启动强制安装

### 2.4 配置初始化
- 检测 `.env` 文件是否存在
- 不存在时从 `.env.example` 复制生成
- 创建必要的运行时目录：`tmp_files/`、`data/`

### 2.5 服务启动
- 使用 uvicorn 启动服务
- 从 `.env` / `config.py` 读取端口和 host 配置
- 支持 `--reload` 开发模式（通过参数控制）
- 支持 `--port` 和 `--host` 命令行覆盖
- 启动前检查端口是否被占用，给出明确提示

### 2.6 命令行参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--port` | 8080 | 服务端口 |
| `--host` | 0.0.0.0 | 绑定地址 |
| `--reload` | 关闭 | 开发模式（热重载） |
| `--no-check` | 关闭 | 跳过环境检查和依赖安装 |

---

## 三、平台支持

| 脚本 | 平台 |
|------|------|
| `start.ps1` | Windows PowerShell |
| `start.sh` | Linux / macOS |

---

## 四、非功能需求

- 脚本无外部依赖（仅使用系统自带的 shell 和 Python）
- 每一步有清晰的日志输出（彩色标识成功/失败/警告）
- 异常退出时返回非零 exit code
- 脚本编码为 UTF-8 with BOM（PowerShell 兼容中文输出）

---

## 五、用户故事

1. **新开发者**：克隆项目后执行 `./start.ps1`，一键完成环境搭建并启动服务
2. **日常开发**：执行 `./start.ps1 --reload` 启动开发模式
3. **运维部署**：执行 `./start.sh --port 9000` 指定端口启动生产服务
4. **快速跳过**：执行 `./start.ps1 --no-check` 跳过检查直接启动

---

## 六、验收标准

1. Windows PowerShell 下执行 `./start.ps1` 能正常启动服务
2. 无虚拟环境时自动创建并安装依赖
3. 无 `.env` 文件时自动从 `.env.example` 生成
4. Python 版本不满足时给出明确错误提示
5. 端口被占用时给出明确提示
6. `--reload` 参数能启用热重载
7. `--port` 和 `--host` 参数能覆盖默认值
8. `--no-check` 参数能跳过环境检查和依赖安装
