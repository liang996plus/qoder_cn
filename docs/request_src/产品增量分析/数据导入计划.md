# 产品增量分析基础数据导入计划

## 1. 概述

将产品增量分析的 3 张 Excel 基础数据表导入到 hiagent 的 SQLite 数据库中，供后续 Pipeline 分析消费。

## 2. 数据源清单

| # | 文件名 | 说明 | 行数(约) | 列数 |
|---|--------|------|----------|------|
| 1 | 每日规模余额表.xlsx | 各产品系列在不同日期的当日规模（余额） | ~220 | 6 |
| 2 | 每日规模增量明细表.xlsx | 子产品维度的每日增长/流失/净增长明细 | ~350+ | 12 |
| 3 | 每月增量目标表.xlsx | 按期限分类和渠道的月度增量目标及预测 | ~45 | 8 |

## 3. 表结构设计

### 3.1 daily_balance（每日规模余额表）

| 列名 | 类型 | 说明 |
|------|------|------|
| 产品类型 | TEXT | 固定收益类 / 含权益类 |
| 期限分类 | TEXT | 超短期固收 / 中短期固收 / 长期限固收 / 中短期含权 / 长期限含权 |
| 具体期限 | TEXT | 如 1天（现金管理）、7天、3个月、1年 等 |
| 产品系列 | TEXT | 如 易精灵、慧精灵、天天利、鑫享利7D 等 |
| 数据日期 | TEXT | 数据日期，如 2026-06-05 |
| 当日规模 | REAL | 当日规模（亿元） |

### 3.2 daily_increment_detail（每日规模增量明细表）

| 列名 | 类型 | 说明 |
|------|------|------|
| 子产品代码 | TEXT | 子产品代码 |
| 母产品代码 | TEXT | 母产品代码 |
| 资金交收日 | TEXT | 资金交收日，如 20260601 |
| 产品名称 | TEXT | 产品全称 |
| 产品形态 | TEXT | 现金型 / 持有期 / 周开 / T+1日开 / 封闭 |
| 期限分类 | TEXT | 超短期固收 / 中短期固收 / 长期限固收 / 中短期含权 / 长期限含权 |
| 产品系列 | TEXT | 产品系列名称 |
| 销售渠道 | TEXT | 销售渠道 |
| 增长(元) | REAL | 增长金额 |
| 流失(元) | REAL | 流失金额 |
| 净增长(元) | REAL | 净增长金额 |
| 映射 | TEXT | 业务映射分类 |

### 3.3 monthly_increment_target（每月增量目标表）

| 列名 | 类型 | 说明 |
|------|------|------|
| 月份 | TEXT | 月份（Excel 序列号，导入时转为日期） |
| 期限分类 | TEXT | 期限分类 |
| 目标标签 | TEXT | 一级渠道分类 / 业务标签 |
| 目标标签说明 | TEXT | 二级渠道分类 / 标签补充说明 |
| 增量目标_新增规模 | REAL | 新增规模目标（亿元） |
| 增量目标_流失规模 | REAL | 流失规模目标（亿元） |
| 增量目标_净增量 | REAL | 净增量目标（亿元） |
| 增量预测逻辑 | TEXT | 预测依据说明 |

## 4. 导入方案

### 4.1 技术路径

编写一个独立 Python 导入脚本 `import_data.py`，直接调用项目已有的 `app.core.db` 模块完成入库，复用现有基础设施，无需新增 API 或修改服务代码。

### 4.2 导入步骤

1. **初始化数据库**：调用 `init_db()` 确保 `_datasets` 元数据表存在
2. **读取 Excel**：使用 pandas 读取 `docs/request_src/产品增量分析/` 下的 3 个 .xlsx 文件
3. **数据预处理**：
   - 每月增量目标表的"月份"列为 Excel 序列号（如 46174），转换为标准日期格式（2026-06）
   - 空值统一处理
4. **逐表入库**：调用 `ingest_dataframe()`，使用 `create` 模式，指定语义化表名
5. **验证**：查询各表行数，确认导入成功

### 4.3 表名映射

| 源文件 | SQLite 表名 |
|--------|-------------|
| 每日规模余额表.xlsx | daily_balance |
| 每日规模增量明细表.xlsx | daily_increment_detail |
| 每月增量目标表.xlsx | monthly_increment_target |

### 4.4 执行方式

```powershell
cd e:\qoder_p
python -m scripts.import_data
```

## 5. 验收标准

- 3 张表全部成功入库，`_datasets` 元数据表中有对应记录
- 各表行数与源文件一致
- 可通过 `/api/v1/data/datasets` 接口查看已入库数据集列表
- 可通过 `/api/v1/data/datasets/{id}/query` 接口执行 SQL 查询验证数据正确性
