### hiagent
- 定义：本项目中基于 Dify/Coze 等平台构建的 AI Agent 应用，面向竞品分析、机构行为分析、产品规模增量分析等多种业务分析场景，通过配置驱动的流水线引擎统一编排数据获取、处理与输出。
- 别名：hiagent_辅助_Web_服务

### Pipeline 引擎
- 定义：hiagent 的核心架构组件：按 YAML 场景配置顺序执行步骤链（Step），通过 PipelineContext 在步骤间传递中间数据，支持条件分支、步骤级错误处理（skip/abort）及独立日志与耗时记录。
- 别名：流水线引擎、pipeline_engine

### Connector
- 定义：数据连接器抽象层，封装数据库直连、REST API 调用、文件上传/下载/对象存储等数据源接入方式，统一返回 DataFrame，凭据从环境变量读取，采用注册表模式扩展新类型。
- 别名：数据连接器、connector 层

### 场景配置
- 定义：以 YAML 描述的业务场景定义，包含 data_sources（数据源）、pipeline（处理步骤链）和 outputs（chart/table/report/file/summary 五种输出类型），用于驱动 Pipeline 引擎运行。
- 别名：scenario 配置、场景 YAML

### 原子 API
- 定义：Pipeline 之外的细粒度能力接口（如 /api/v1/data/*、/api/v1/visual/*），供 Agent 自行编排组合；与 Pipeline API（POST /api/v1/pipeline/run）形成双调用模式。
- 别名：原子能力接口

### API Key 认证
- 定义：通过请求头 X-API-Key 进行鉴权的安全机制，作为 hiagent 统一接口的认证方式，配合文件沙箱、SQL 注入防护等安全策略。
- 别名：X-API-Key
